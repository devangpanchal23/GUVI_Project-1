2. PROJECT OVERVIEW

The Student Management System is a lightweight, console-based Core Java
application built to maintain and manage student academic records.
Users interact with the system entirely through an intuitive terminal menu.

During application runtime, all active student records are managed
in-memory using an ArrayList<Student>. Records are automatically
persisted to a local flat text file (students.txt) using pipe-delimited
formatting, ensuring data is preserved across sessions without requiring
external database engines.

------------------------------------------------------------

- Java (JDK 8 or higher)

4. PROJECT FEATURES

1. Add Student
   Prompts for Student ID, Name, Age, Course, and Email.
   Verifies that the Student ID is a positive integer and is unique.
   Instantiates a Student object, stores it in the collection, and
   saves the record to students.txt.

2. View All Students
   Displays every student record currently in memory.
   If no records exist, prints "No student records found."

3. Search Student
   Prompts for a Student ID and performs a linear search.
   Displays full student details if found, or "Student not found."

4. Update Student
   Prompts for the Student ID of an existing student.
   If found, displays current details and prompts for updated Name,
   Age, Course, and Email.
   The Student ID remains unchanged to protect record integrity.
   Saves updated details to students.txt immediately.

5. Delete Student
   Prompts for the Student ID to remove.
   Removes the matching Student from the ArrayList and updates
   students.txt. Displays confirmation or "Student not found."

6. Exit Application
   Displays a friendly closing message and terminates execution cleanly.

5. STUDENT INFORMATION

Each student record consists of five fields:

- Student ID : int (Unique positive whole number)
- Name       : String (Full name of student, non-empty)
- Age        : int (Age between 5 and 100)
- Course     : String (Academic course/program name, non-empty)
- Email      : String (Email address containing '@' and '.')

6. PROJECT STRUCTURE

The project is organized in a single root package for clarity:

StudentManagementSystem/
│
├── Main.java
│   Contains the main() method, terminal menu loop, and defensive
│   user-input validation methods. Delegates business operations
│   to StudentManager.
│
├── Student.java
│   The entity model representing a student. Implements encapsulation
│   with private attributes, constructor, getters, setters, formatted
│   console output, and delimited file-string conversion.
│
├── StudentManager.java
│   Encapsulates the in-memory ArrayList<Student>. Implements CRUD
│   operations (add, view, search, update, delete) and handles file
│   persistence (loadStudentsFromFile, saveStudentsToFile).
│
├── students.txt
│   Plain-text persistent storage storing records separated by '|'.
│
└── setup_guide.txt
    Comprehensive setup, technical overview, and execution guide.

12. DATA STORAGE

File: students.txt
Format: Pipe-delimited plain text

Format specification:
studentId|name|age|course|email

Example entries:
101|Rahul Patel|20|BCA|rahul@example.com
102|Devang Panchal|20|GUVI Full Stack Website Development With AI|devangpanchal2305206@gmail.com

Persistence Behavior:
- When Main starts, StudentManager reads students.txt.
- Valid records are instantiated into Student objects in the ArrayList.
- Any addition, update, or deletion rewrites the file immediately.
- Records remain intact across application restarts.

------------------------------------------------------------

13. INPUT VALIDATION

- Student ID:
  * Must be a positive integer greater than 0.
  * Must be unique (duplicates are rejected with an explicit message).
- Name:
  * Cannot be empty or whitespace-only.
- Age:
  * Must be a whole number between 5 and 100 inclusive.
- Course:
  * Cannot be empty or whitespace-only.
- Email:
  * Cannot be empty.
  * Must contain '@' and '.' characters.
- Menu Selection:
  * Non-numeric choices (e.g., 'abc') or out-of-range numbers
    (e.g., 0, 7) display clear error notices without terminating.
- Defensive Scanner Reading:
  * All input is read via scanner.nextLine().trim() to prevent
    the common Java Scanner newline skipping defect.

------------------------------------------------------------

14. ERROR HANDLING

- Duplicate Student ID:
  Checks existing records before accepting data and informs user.
- Student Not Found:
  Displays "Student not found." if search, update, or delete fails.
- Empty Student List:
  Displays "No student records found." on viewing an empty system.
- Non-numeric Input:
  Catches NumberFormatException gracefully and re-prompts the user.
- Missing students.txt:
  Starts cleanly with an empty list without throwing FileNotFoundException.
- Corrupted File Records:
  If a line has missing fields or non-numeric IDs/ages, StudentManager
  logs a notice, skips that single line, and loads all other valid records.

15. OOP CONCEPTS

- Class and Object:
  Student defines the template; each real student record is an object.
- Encapsulation:
  Attributes are private; getters/setters mediate access.
- Constructors:
  Guarantees all student fields are initialized upon creation.
- Separation of Concerns:
  Main manages UI/CLI, Student models data, StudentManager handles CRUD.

------------------------------------------------------------

16. COLLECTION FRAMEWORK

Class: java.util.ArrayList<Student>

Why ArrayList:
- Provides dynamic array resizing as records are added or removed.
- Fast, index-based traversal for viewing and searching.
- Standard, simple Core Java collection suitable for learning.

------------------------------------------------------------

17. FILE HANDLING

- FileReader and BufferedReader:
  Used to read records line-by-line efficiently.
- FileWriter and BufferedWriter:
  Used to write records back to disk with proper line terminators.
- Delimiter Splitting:
  Uses line.split("\\|") to safely parse pipe delimiters without
  regex collision.
- Resource Management:
  File streams are closed safely in finally blocks.

18. TROUBLESHOOTING

Problem:
'javac' is not recognized as an internal or external command.
Solution:
JDK is not installed or your system PATH variable does not include
the JDK bin folder. Install JDK and add its bin folder to PATH.

Problem:
"No student records found." when viewing.
Solution:
The file students.txt is empty or was not found. Add a student
using Option 1 to create the initial file.

Problem:
Non-numeric input loop when entering ID.
Solution:
Enter whole numbers only (e.g., 101, 102). Do not include letters
or symbols.
